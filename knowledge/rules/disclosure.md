# Disclosure

Generated content must be honest about authorship, affiliations, sponsorship, and AI assistance.

Use disclosure when:

- The platform requires AI disclosure.
- The post is sponsored or commercially motivated.
- The author has a financial interest in the project.
- Benchmarks, testimonials, or user numbers could affect trust.

Never invent:

- User counts
- Revenue
- Benchmarks
- Customer names
- Endorsements
- Repository URLs, npm package names, or website domains (leave blank or use placeholders like `[Insert Link]`)
- Demo links or screenshots
