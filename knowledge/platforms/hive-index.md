## Trigger Context

Triggered by mentions of 'Hive Index', 'community directory', or 'finding online communities'

## Language

The primary language for directory entries and all interface text is **English (US/International)**. While Hive Index catalogs communities in dozens of languages, every submission must include an English description and tags for indexing and search. If your community is non-English, include the native name alongside an English translation. The platform's tagging system (e.g., "Language: Spanish") handles linguistic classification — do not assume readers will infer the language from context.

## Good Fit

- A community platform (Discord, Slack, Telegram group, forum, subreddit) centered around a specific tech stack, framework, or developer interest.
- A local or regional developer meetup, conference, or user group with an online presence.
- A niche interest group (e.g., game development, data visualization, open-source hardware) that is underrepresented in mainstream directories.
- A community that has a clear, searchable purpose and is open to new members (public or by application).
- A project where the primary value is the community discussion itself, not just the project's documentation or code repository.

## Poor Fit

- A single GitHub repository with no associated community space (e.g., a library with only issues and PRs).
- A commercial product's support forum that requires a paid subscription to access.
- A community that is invitation-only and does not accept new members.
- A personal blog, portfolio site, or newsletter without a discussion or group component.
- A project that is primarily a documentation site with no interactive community element.

## Format And Style Notes

- Lead with the community's purpose.
- Specify the format and platform.
- Mention the target audience explicitly.
- Use tags to describe the technology stack or topic.
- Describe community size or activity level factually.
- Avoid subjective praise or marketing language.
- Keep descriptions to 1–3 sentences.
- Use the exact official name of the community.

## Tone

Write a factual, searchable directory entry that helps a researcher find the right community — no hype, no personality, just clarity and accuracy.
