## Good Fit

- Open-source libraries or tools that demonstrate advanced engineering skills (e.g., distributed systems, machine learning, DevOps automation)
- Full-stack web applications built with modern frameworks (React, Node.js, Python/Django, Go)
- Mobile applications (React Native, Flutter, Kotlin) with clean architecture and testing
- Developer tooling or productivity enhancers (CLI tools, CI/CD pipelines, monitoring solutions)
- Projects that solve real-world African infrastructure or business challenges (fintech, healthtech, agritech)

## Poor Fit

- Content management systems or WordPress themes
- Simple CRUD applications with no technical complexity
- Projects with poor documentation, no README, or no test coverage
- Hobby projects with no production-readiness indicators
- Projects that rely on outdated or unmaintained dependencies

## Format And Style Notes

- Lead with the opportunity, not the company. Immediately state the role, impact, and why it matters.
- Use bullet lists for requirements instead of paragraphs. Developers scan for keywords.
- Highlight metrics and outcomes. Andela's audience values measurable impact.
- Avoid emojis, colored text, and custom formatting. The brand is strict and professional.
- Use code blocks with language specification for technical content. Proper syntax highlighting is expected.
- Keep paragraphs short (max 3 sentences). Andela's audience is busy and decision-focused.
- Use tables only for comparison data (salary, benefits, tech stack). Do not use tables for layout.
- End with a clear call to action (CTA). Every piece of content should direct the reader to the next step.

## Tone

Professional, credential-focused, and opportunity-driven — write as if every word is being evaluated by a hiring manager seeking the top 1% of global engineering talent.
