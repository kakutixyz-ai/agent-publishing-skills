## Language

The platform's primary communication language is **English** for all technical content, code snippets, and resource sharing. **Arabic (Modern Standard Arabic)** is the secondary language, used for community announcements, event promotions, and introductions. Best practice is to use bilingual posts: English for technical substance with Arabic for community context. Posts in English-only for technical topics are well-received. Posts in Arabic-only for technical topics limit reach. For regional social posts (e.g., meetups, job openings), include an Arabic intro followed by English details.

## Good Fit

- Open-source libraries or tools that solve common developer problems (e.g., authentication, data validation, localization)
- Developer tools with specific relevance to the MENA region (e.g., Arabic text processing, Hijri calendar libraries, regional payment gateways)
- Tutorials and learning resources for web development, DevOps, or mobile development
- Job boards or career resources targeting Arab tech professionals
- Community-driven projects that welcome contributions from Arabic-speaking developers

## Poor Fit

- Consumer apps or games with no developer angle (e.g., fitness trackers, photo editors, social media clones)
- Projects that require extensive non-technical explanation or marketing fluff
- Proprietary, closed-source commercial products with no community benefit
- Projects with zero documentation or README in English
- Projects that ignore the regional context entirely (e.g., a weather app focused only on European cities with no localization)

## Format And Style Notes

- Use clear, descriptive titles that include the project's purpose and technology stack.
- Open with a one-sentence summary of what your project does and why it matters.
- Use short paragraphs (2-3 sentences max) and bullet points for features.
- Include a code snippet showing installation and basic usage.
- Tag the post with relevant technology labels (e.g., JavaScript, Python, DevOps).
- Mention any regional relevance explicitly (e.g., "works with Saudi payment gateways").
- End with a call to action that invites collaboration or feedback.
- Use images sparingly and only when they add technical value (e.g., architecture diagram, screenshot of working output).
