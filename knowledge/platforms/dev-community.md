## Trigger Context

Triggered by mentions of 'DEV Community', 'dev.to', or 'DEV' as a publishing platform for software developers.

## Language

The primary language of DEV Community is **English (US/International standard)**.

## Good Fit

- Educational tutorials: Step-by-step guides that teach a specific technology, library, or concept (e.g., "How to Build a REST API with Go").
- Problem-solution posts: Articles that explain a specific bug or challenge and how you fixed it (e.g., "Fixing CORS Errors in React").
- Open-source project walkthroughs: Detailed explanations of how an open-source tool works internally, or how to contribute to it.
- Beginner-friendly content: Introductions to a language, framework, or best practice, tagged with `#beginners`.
- Career and learning advice: Posts about imposter syndrome, learning strategies, or transitioning into tech.

## Poor Fit

- Pure marketing or sales pitches: Posts that are essentially ads for a commercial product without providing value.
- Listicles without original insight: "Top 10 JavaScript Frameworks" with no personal experience or analysis.
- Low-effort reposts: Copy-pasting a README or a tweet thread without adding context or explanation.
- Highly academic or theoretical papers: Research papers or dense mathematical proofs with no practical application.
- Content unrelated to software development: Travel blogs, cooking recipes, or general lifestyle content.

## Format And Style Notes

- Start with a problem statement. Immediately tell the reader what they will learn and why it matters.
- Use personal anecdotes. Share your own struggles and failures to build rapport.
- Break content into numbered steps. Use `##` and `###` headers; never use `#` in the body.
- Place code blocks after explanations. Never lead with a huge code block.
- Use fenced code blocks with language identifiers. Always specify the language for syntax highlighting.
- Include a custom cover image. Use high-contrast images with text/diagrams, not generic stock photos.
- Use blockquotes for warnings or tips. This draws attention to important caveats.
- End with a call to action or open question. Invite discussion and feedback.
