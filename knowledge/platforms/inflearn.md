## Good Fit

- A comprehensive Korean-language video course teaching a specific programming language (e.g., "Spring Boot로 REST API 만들기") or framework.
- A structured tutorial series with clear prerequisites, a detailed curriculum, and practical Korean-language examples (e.g., Korean payment gateways, government API integrations).
- A project that solves a common problem for Korean developers, such as local deployment, Korean NLP, or Korean-specific data processing.
- A library or tool that requires extensive Korean documentation and a dedicated Q&A community for support.
- A bootcamp-style project that can be broken into 10+ hours of video content with quizzes and assignments.

## Poor Fit

- A single blog post, podcast episode, or short-form content — Inflearn is an LMS for courses, not articles.
- An English-only project with no Korean translation or explanation.
- A project targeting beginners but lacking a structured curriculum or clear learning objectives.
- A tool that is already well-covered by existing Korean courses with no unique angle.
- A project that requires frequent real-time updates or community discussion (use Discord or a forum instead).

## Format And Style Notes

- Use a formal, respectful tone (존댓말) throughout. Avoid casual English-Korean mixing (e.g., "이거 완전 easy함").
- Structure content with clear headings (H2, H3). Korean users expect a hierarchical outline.
- Use code blocks with language specification. Syntax highlighting is expected.
- Provide a detailed curriculum as an ordered list or table. Users want to know exact section contents.
- Include a clear problem statement in the first 1-2 sentences. Hook the user immediately.
- Use bullet lists for prerequisites and target audience. Clarity is key.
- Limit emoticons to functional emphasis only. No Western internet slang.
- Add generous line breaks between paragraphs. Korean text is dense; mobile readability matters.
