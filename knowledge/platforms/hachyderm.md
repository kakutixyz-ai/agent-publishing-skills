## Format And Style Notes

- Lead with a clear, standalone statement. Avoid greetings or filler. State the core value proposition immediately.
- Use content warnings (CW) for anything that might be controversial or off-topic. The CW line should be descriptive.
- Break long content into threads. Use `1/n`, `2/n` numbering or reply to your own post.
- Use code blocks for configuration examples. Avoid inline code for multi-line snippets.
- Use plain URLs without link shorteners. Trust is earned through transparency.
- Limit hashtags to 2-3 relevant ones. Use tags that actual users search for.
- Share specific, technical details. Avoid vague claims. Include numbers, benchmarks, or architecture decisions.
- End with a clear call to action that respects the community. Ask for feedback, not stars.
