# Security and Safety

This library is designed for draft generation, not account automation.

## Non-Negotiable Rules

- Never auto-publish content.
- Never ask for platform passwords, session cookies, or API tokens unless a specific integration explicitly requires them and the user has approved that workflow.
- Do not evade moderation, rate limits, spam filters, or disclosure requirements.
- Do not generate fake testimonials, fake user counts, fake benchmarks, or fake endorsements.
- Disclose AI assistance when the target platform, community norm, or user policy requires it.

## Review Requirement

Run `skills/reviewer` before any generated draft is handed off for publishing.
