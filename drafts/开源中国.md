# agent-publishing-skills：让 AI Agent 学会跨平台发布的开源技能库

> 覆盖 91 个开发者和技术社区，支持中/英/日/韩等多语言平台，已发布到 npm

## 项目简介

**agent-publishing-skills** 是一个面向 AI Agent 的通用发布技能库。它解决的核心问题是：AI 编程助手（Claude Code、Gemini CLI、Codex 等）在「把项目介绍发布到不同技术社区」这个场景下，缺乏平台适配能力——要么生成千篇一律的文案，要么不了解各平台的内容规范。

- **仓库地址**：[https://github.com/anomalyco/agent-publishing-skills](https://github.com/anomalyco/agent-publishing-skills)
- **npm 包**：[https://www.npmjs.com/package/@kakuti/agent-publishing-skills](https://www.npmjs.com/package/@kakuti/agent-publishing-skills)
- **许可证**：MIT
- **技术栈**：Node.js、JSON Schema、Markdown

## 功能特性

### 三层解耦架构

```text
knowledge/ (平台知识层)
  ├── platforms/          # 91 个平台的标准化知识档案
  │   ├── csdn.md         # CSDN 技术博客
  │   ├── 掘金.md         # 稀土掘金
  │   ├── 知乎.md         # 知乎
  │   ├── 开源中国.md     # OSChina
  │   └── ...
  ├── rules/              # 全局安全规则
  └── styles/             # 内容风格模板

skills/ (执行技能层)
  ├── planner/            # 分析项目，推荐平台
  ├── writer/             # 生成基础草稿
  ├── adapter-*/          # 平台适配器（6 个专用 + 5 个通用）
  └── reviewer/           # 审查合规性
```

### 核心技能工作流

**planner → writer → adapter → reviewer → 人工发布**

1. **planner**：分析 `project-brief.json`，根据项目类型和内容证据，推荐适合发布的平台并打分。
2. **writer**：将项目简介转化为一份「基础草稿」——这个草稿不针对任何具体平台，只包含项目核心信息和价值主张。
3. **adapter**：根据目标平台的知识档案，将基础草稿适配为平台特化的草稿。
4. **reviewer**：审查最终草稿是否符合平台规范、是否包含垃圾内容、是否需要披露声明。

### 平台覆盖

目前已覆盖 **91 个**开发者和技术社区平台，按语言分布：

| 语言 | 平台数量 | 代表平台 |
|------|----------|----------|
| 中文 (zh) | 6 | CSDN、掘金、知乎、V2EX、少数派、开源中国 |
| 英文 (en) | 50+ | DEV Community、Hacker News、Reddit、Product Hunt、Medium |
| 日文 (ja) | 2 | Zenn、Qiita |
| 韩文 (ko) | 2 | Velog、Disquiet |
| 其他 | 30+ | 各语言技术社区 |

### 安全规则

项目内置四条不可绕过的安全约束：

- **no-auto-publish**：所有输出始终为 `draft` 状态，不触发任何发布操作。
- **anti-spam**：禁止多平台重复内容，禁止索要点赞/标星，要求提供可验证证据。
- **disclosure**：AI 生成或商业赞助内容必须透明披露。
- **factual-accuracy**：禁止编造用户量、收入、基准测试等数据。

## 快速开始

```bash
# 全局安装
npm install -g @kakuti/agent-publishing-skills

# 为不同 Agent 运行时安装技能
agent-publishing-skills install claude      # Claude Code
agent-publishing-skills install gemini      # Gemini CLI
agent-publishing-skills install opencode    # OpenCode
agent-publishing-skills install codex       # OpenAI Codex CLI
```

安装后在项目目录准备 `project-brief.json`：

```json
{
  "name": "项目名称",
  "summary": "一句话描述你的项目",
  "audience": ["目标用户群"],
  "status": "launched",
  "project_type": "developer library",
  "links": {
    "website": "项目网站",
    "repository": "GitHub 地址"
  }
}
```

然后 Agent 就可以执行 `planner → writer → adapter → reviewer` 工作流生成平台草稿。

## 与同类项目的差异

| 维度 | agent-publishing-skills | 通用 AI 写作工具 | 手工跨平台工具 |
|------|------------------------|-------------------|----------------|
| 平台知识 | 91 个平台的结构化描述 | 无 | 无 |
| 平台适配 | 自动适配格式和语调 | 统一文案 | 人工调整 |
| 安全约束 | 内置反垃圾和披露规则 | 无 | 依赖人工 |
| 发布操作 | 绝不自动发布 | 部分支持 | 支持排期发布 |
| 适用场景 | AI Agent 技能扩展 | 营销文案 | 社交媒体管理 |
