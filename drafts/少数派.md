# 给我 5 分钟，让你的 AI 编程助手学会跨平台发布——agent-publishing-skills 体验报告

> 一个命令行工具，让 Claude、Gemini、Codex 等 AI Agent 掌握 91 个平台的内容发布规范

## 我遇到的问题

作为一个经常在掘金、V2EX、GitHub Discussions 之间搬运项目更新的人，我深有体会：**在不同平台发布同一个项目信息，绝对不是 Ctrl+C Ctrl+V 就能搞定的事**。

在掘金上你要写技术分析，在 V2EX 上你只能贴 200 字加一个链接，在知乎上你得用问答体，在少数派上你要讲使用场景——不同平台的读者期待完全不同的内容。

最近我开始重度使用 Claude Code 来辅助开发，一个让我困扰的场景是：当我让 Agent "帮我把这个更新发到掘金和 V2EX 上"，它给出的内容要么是同样的文案改了个标题，要么完全不对平台的调性。

直到我发现了 [agent-publishing-skills](https://github.com/anomalyco/agent-publishing-skills)。

## 它是什么

一句话概括：**agent-publishing-skills 是一套给 AI Agent 安装的「发布技能包」**。安装后，你的 AI 编程助手就能像经验丰富的技术作者一样——先规划发哪些平台，再为每个平台撰写不同角度的草稿，最后自查内容是否合规。

它本质上是一个 npm 包，核心是两个目录：

- `knowledge/`：91 个平台的「说明书」。每个平台一个 Markdown 文件，描述了该平台用什么语言、适合什么内容、格式有什么要求、语调应该怎样。例如 V2EX 的档案会告诉你「不要用 Markdown 标题，用加粗+空行代替」。
- `skills/`：4 个「工作规范」。planner（规划发什么平台）、writer（写基础草稿）、adapter（适配到具体平台）、reviewer（审查合规性）。

## 上手体验

### 安装

```bash
npm install -g @kakuti/agent-publishing-skills

# 以 Claude Code 为例安装技能
agent-publishing-skills install claude

# 也支持其他 Agent 运行时
agent-publishing-skills install opencode
agent-publishing-skills install gemini
```

安装后，在项目目录下放一个 `project-brief.json`：

```json
{
  "name": "你的项目名",
  "summary": "一句话描述",
  "audience": ["目标读者"],
  "project_type": "developer library",
  "links": {
    "repository": "GitHub 地址"
  }
}
```

然后 Agent 就能按工作流执行了。

### 实际效果

我用同一个 `project-brief.json`（描述的就是 agent-publishing-skills 自己）测试了六个中文平台的输出：

**CSDN** 的草稿采用了「踩坑教程」体——以步骤式标题（一、背景，二、核心设计……）+ 代码块 + 版本标注组织内容，符合 CSDN 读者「复制即用」的期待。

**掘金** 的草稿则完全不同——开头就上 Mermaid 架构图，用表格对比专用适配器和通用适配器的策略，内容从架构设计展开到安全规则引擎的实现细节。

**V2EX** 的帖子只有约 200 字，用加粗代替标题，直接给出项目地址和技术讨论点。

虽然输出质量很大程度取决于底层 LLM 的能力，但仅从「角度选择」和「格式适配」这两个维度看，技能包确实提供了有价值的方向引导。

## 值得关注的设计细节

### 绝不自动发布

这是我最欣赏的设计决策。所有输出状态都是 `draft`（草稿），技能本身没有任何发布能力。生成的草稿需要你人工审核后再手动发布到对应平台。

在 AI Agent 越来越自主的今天，这种「硬约束」设计让人安心。

### 反垃圾检测内置

技能包会自动检查：是否在多个平台间重复了相同内容？文字中是否含有索要点赞/标星的用语？是否缺失可验证的证据链接？

这些检查不是建议，是硬性规则。

### 透明披露

如果内容涉及 AI 生成或商业赞助，技能会要求 Agent 主动标注披露声明。

## 当前局限

几个需要注意的点：

1. **中文平台的适配深度还有提升空间**。CSDN、掘金、知乎、V2EX、少数派、开源中国六家目前共用 `adapter-technical-blog` 或 `adapter-community-discussion` 通用适配器，没有像 Zenn（日文）那样的专用适配器。
2. **平台档案需要社区共建**。91 个平台中，部分平台的档案描述可能不够细致，需要用过的人持续完善。
3. **适合 Agent 原生用户**。如果你不习惯用 Claude Code/Gemini CLI 这类工具，上手有一定门槛。

## 适合谁用

- 使用 Claude Code、Gemini CLI、Codex 等 AI Agent 的开发者。
- 需要同时在多个技术社区发布项目更新的开源维护者。
- 想探索「Agent 技能系统」设计范式的技术作者。
