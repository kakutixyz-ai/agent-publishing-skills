# Crosspost Technical Blog

Use this workflow to adapt one technical article for multiple developer publishing platforms.

## Skill Sequence

1. `skills/planner`
2. `skills/writer` if no base article exists
3. Prefer `skills/platform-writers/<target-platform>` for each selected target.
4. Fall back to the matching generic adapter only when no dedicated platform writer exists.
5. `skills/reviewer`

## Notes

Do not post identical text everywhere. Each platform version should change the opening, title, formatting, and call to action.
