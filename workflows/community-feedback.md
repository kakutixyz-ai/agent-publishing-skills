# Community Feedback

Use this workflow when the goal is feedback, not launch traffic.

## Skill Sequence

1. `skills/planner`
2. `skills/writer`
3. Prefer `skills/platform-writers/<target-platform>` when it exists.
4. Fall back to `skills/adapter-community-discussion` only when no dedicated platform writer exists.
5. `skills/reviewer`

## Drafting Principle

Ask a specific technical question. Do not disguise promotion as feedback.
